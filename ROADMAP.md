# FrameByFrame Roadmap

This roadmap describes the work planned for FrameByFrame `v1.0.0`.

## Editor

- [x] Add timeline scrubber features
  - [x] Display scrollable frame previews and navigate between frames
  - [x] Duplicate frames
  - [x] Copy and paste frames
  - [x] Reorder frames
- [x] Add audio support, allowing a user to add and modify audio tracks from the timeline
- [x] Add support for renaming projects
- [x] Add new brush types for paintbrush and eraser
- [x] Add custom brush editor/creator
- [ ] Support 3rd party (e.g. photoshop) brushes
- [x] Add support for arbitrary layer counts
- [x] Add customizable canvas size
- [x] Add support for toggling layer visibility
- [x] Add customizable onion skin (both number of frames before/after, and opacity)
- [x] Add undo / redo support
- [x] Add toggleable autosave
- [x] Add free-form selection tool (move, resize, rotate, copy, paste, delete)
- [x] Playing an animation starts from currently selected frame
- [x] Support for modifying background layer (transparent or changing color)

## Export

- [x] Add support for exporting different file types (gif, mov, mp4, png, spritesheet)
- [x] Allow exporting to selectable custom directory
- [x] Add export progress and useful error messages.
- [x] Allow exporting individual frame range

## UI

- [ ] All icons and graphics should be custom made
- [x] Add consistent, readable typography throughout the application
- [x] All UI elements should be resizable
- [x] Drawing canvas can be panned, rotated, and zoomed without affecting final export
- [x] Projects view should display projects in a flex-style grid allowing up to 6 projects visible at once in a 2x3 grid
- [x] Add loading, progress, success, and actionable error feedback
